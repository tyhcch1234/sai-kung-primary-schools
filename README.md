## 重要限制

- **小六學生人數為推算值**：小六班數 × 25 人。《小學概覽》只公布班數，不公布各級實際學生人數；25 人為 95 校網小班教學標準班額。
- 2026／27 班數為教育局 2026 年 3／4 月批核數字，最終可能微調。
- 社交平台只列可確認的官方帳號；未見公開專頁者標示為「未見」。
- 「宣傳策略」分類為基於公開資料的分析框架，非學校官方定位。
